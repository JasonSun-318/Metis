# Sandbox Extension Example

This is a legacy customization example that replaces the Bash tool to demonstrate extension APIs and custom SRT configuration. ArcMind now has a built-in Ask/Auto permission and SRT boundary; normal users do not need this extension.

Installing the example means trusting its TypeScript code. Its configuration does not weaken or replace ArcMind's fixed permission policy for model tool calls, and it must not be presented as the core security boundary. See [Permissions and Sandbox](../../../docs/permissions.md).
