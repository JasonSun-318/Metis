# 定时任务

Metis 只在 Chat 模式提供定时任务。桌面端通过左侧的 **Scheduled tasks** 管理任务；终端可用 `/schedule`。两种入口共用同一份全局存储、调度器和运行历史，Code 模式不显示任务定义或任务生成的会话。

## 创建、模型和目录

任务包含三个用户字段：必填显示名称、可选显示说明和必填执行说明。只有执行说明会作为模型提示词。任务还会固定保存创建时选择的 `{ provider, modelId }` 和设备 IANA 时区；之后供应商或模型被移除时不会自动降级，执行会记录 `MODEL_UNAVAILABLE` 并暂停任务，等待用户重新选择已配置模型。

支持一次、每天、每周多个星期、每月指定日期，以及每隔若干分钟或小时。夏令时由现有时间计算规则处理；离线超过一分钟的到期执行记为 `missed`，同一任务重叠记为 `skipped`，都不会自动补跑。

执行目录只有两种：

- 选择一个用户目录的 Chat 项目后，后续运行固定使用该目录；
- 不选择项目时，使用 `~/.metis/agent/schedule-workspaces/<taskId>/`（Windows 为 `%USERPROFILE%\.metis\agent\schedule-workspaces\<taskId>\`），并在设置 `METIS_CODING_AGENT_DIR` 时改用该根目录。

编辑名称、说明、模型、周期或目录只影响未来运行；历史记录保留创建运行时的完整不可变快照。

## 安全、在线条件和 Keep Awake

调度器只在 Metis CLI 或 App Server 进程运行时工作，不安装系统服务。多个进程通过全局领导锁协调，最多并行两个不同任务，同一任务不会并行执行。

无人值守执行只开放 `read`、`grep`、`find`、`ls`、`write`、`edit`、`bash`、`web_fetch` 和 `web_search`。文件写入受工作目录限制；Bash 拒绝网络、破坏性、提权和外部副作用命令；也不加载 Skills、Extensions、MCP/Connectors、提示词模板、主题、项目长期记忆或 Dream 自动记忆。隔离运行时不可用时直接失败，不回退到 Full 权限。

桌面端的 Keep Awake 默认关闭。开启后仅在 Metis 运行期间使用 Electron `prevent-app-suspension` 防止系统睡眠，不阻止显示器休眠，也不能在应用退出后继续工作。

## 结果、只读会话和删除

每次真正执行都会新建一个可见、只读的 Chat 会话，名称取自该次运行快照并带 Scheduled 标识。模型失败或中断时，只要会话已经创建，也会保留现场。运行会话不能继续输入、转向、归档、分叉、重命名或单独删除。

暂停保留任务和历史；立即运行不改变原周期。任务正在运行时，编辑和删除返回 `TASK_BUSY`。

删除任务始终停止未来运行、移除任务定义和运行元数据，并把 Metis 管理的任务专属目录移到操作系统废纸篓。用户选择的固定项目目录永远不会被任务删除修改。删除确认框中的 `Also delete all session files generated by this task` 默认不勾选：

- 未勾选时，生成的只读 Chat 会话及其图片、附件、工具输出、Subagent 和 `document-work` 数据全部保留，并继续显示在 Chat Recents；
- 勾选时，所有活动或归档运行会话和经归属校验的会话中间文件，与任务专属目录一起通过一次可恢复的废纸篓事务移除。

删除没有永久删除或 `unlink` 回退。事务使用持久化 staging manifest、单次 Trash 调用、会话租约和路径/符号链接/硬链接校验；失败会回滚，崩溃后会在调度器启动前恢复或完成。

## App Server 接口

能力标识为 `models.v1` 和 `schedules.v2`。模型通过 `model/list` 独立列出，不需要创建隐藏会话。定时任务方法包括：

- `schedule/create`、`schedule/list`、`schedule/get`、`schedule/update`
- `schedule/pause`、`schedule/resume`、`schedule/delete`、`schedule/run-now`
- `schedule/run/list`、`schedule/run/get`、`schedule/run/mark-read`
- `schedule/subscribe`、`schedule/unsubscribe`

列表支持名称/说明搜索、`next_run`、`updated`、`name` 排序及游标分页；运行历史也使用游标分页。实时事件为 `schedule/updated`、`schedule/deleted`、`schedule/runUpdated` 和 `schedule/refreshed`，不包含会话正文、工具参数、思考内容、凭据或内部会话路径。

任务存储损坏时普通会话仍可使用；定时任务方法返回明确的 `SCHEDULE_STORE_CORRUPT`，直到存储被修复。
