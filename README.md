# ArcMind

ArcMind is an extensible general-purpose agent foundation for terminal and application integrations.

## Packages

- `@arcmind/ai`: multi-provider LLM API
- `@arcmind/agent-core`: agent runtime and tool execution
- `@arcmind/coding-agent`: interactive CLI, SDK, and RPC mode
- `@arcmind/tui`: terminal UI components
- `@arcmind/orchestrator`: experimental process orchestration

## Development

Requires Node.js 22.19 or newer.

```bash
npm ci --ignore-scripts
./arcmind-test.sh
```

Run static checks with:

```bash
npm run check
```
